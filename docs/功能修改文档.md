## 🎯 修改内容

### 1. 语音服务模块 (`src/utils/speechService.js`)

#### 新增功能
| 功能 | 方法名 | 说明 |
|------|--------|------|
| 语音播报 | `speak(text, lang)` | 支持中文语音播报 |
| 音量控制 | `setVolume(volume)` | 设置音量 0-100 |
| 页面提示 | `announcePage(pageName, extraInfo)` | 页面进入时语音提示 |
| 语音识别初始化 | `initRecognition(callback)` | 初始化语音识别引擎 |
| 开始监听 | `startListening()` | 开始语音监听 |
| 停止监听 | `stopListening()` | 停止语音监听 |
| 指令处理 | `handleCommand(transcript)` | 解析语音指令 |

#### 支持的语音指令
| 指令 | 功能 |
|------|------|
| "现在是什么页面" / "回答当前页面" / "当前页面" | 语音播报当前页面名称 |
| "进入首页" / "打开首页" / "去首页" | 跳转到用户主页 |
| "进入相机" / "打开相机" / "去相机" | 跳转到相机拍摄页 |
| "进入个人中心" / "打开个人中心" / "去个人中心" | 跳转到个人页 |
| "进入紧急" / "打开紧急" / "去紧急" | 跳转到紧急处理页 |
| "进入监护人主页" | 跳转到监护人主页 |
| "帮助" / "指令" | 播报可用指令列表 |
| "关闭语音" / "停止语音" | 关闭语音控制 |

## 🔧 技术实现

### 语音识别技术栈
- **Web Speech API** (浏览器原生)
- 语音合成：`window.speechSynthesis`
- 语音识别：`window.SpeechRecognition` / `window.webkitSpeechRecognition`

### 浏览器兼容性
- ✅ Chrome 支持
- ✅ Safari 支持
- ✅ Edge 支持
- ⚠️ Firefox 部分支持（需启用实验性功能）

## 🎤 语音控制使用说明

### 开启语音控制
1. 在用户主页点击右上角"开启语音"按钮
2. 听到提示"已开启语音控制"
3. 说出指令即可操作

### 常用指令示例
```
🎤 "现在是什么页面" → 语音回复当前页面
🎤 "进入相机" → 跳转到相机页面
🎤 "进入个人中心" → 跳转到个人页面
🎤 "帮助" → 播报可用指令列表
```
